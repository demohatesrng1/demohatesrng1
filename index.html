01 Projects

Things I've built.

Two systems projects, both measured rather than described.

01

Mimi

On-device Japanese AI voice assistant · C++/Qt6 · macOS

A fully on-device Japanese voice assistant for macOS, ported from a Python prototype to ~17.6K lines of C++/Qt6 so Whisper inference could run on the Metal GPU — 13–15× realtime transcription with speech recognition, the LLM, and synthesis all running locally. Zero cloud dependency.

The always-listening path is a lock-free 30-second ring buffer fed straight from the CoreAudio realtime thread, with voice-activity detection, wake-word spotting, and transcription running in parallel — no dead-air windows, no lock contention mid-conversation.

02

Neural Video Compression Pipeline

DCVC-RT + YOLOv8 · CUDA · PyTorch

Deployed and benchmarked DCVC-RT — a CVPR 2025 real-time neural video codec — on a CUDA GPU server, building the custom C++/CUDA extensions and evaluating rate–distortion performance across four quantization levels on 4K and lower-resolution video.

Then extended the evaluation pipeline in Python/PyTorch to run YOLOv8 multi-object tracking over the decoded frames, producing per-frame tracking data and annotated video — quantifying how far you can compress before downstream computer vision starts to break.
